# 서재욱 · 김현아 모바일 청첩장

2027년 3월 13일 토요일 오후 2시, 로얄파크컨벤션 3층 로얄홀에서 열리는 예식을 위한 모바일 청첩장입니다.

Python으로 내용을 관리하고, GitHub Actions가 GitHub Pages용 정적 웹사이트를 자동으로 생성합니다.

## 현재 반영된 내용

- 신랑 서재욱 · 신부 김현아
- 양가 부모님 성함과 아들·딸 표기
- 예식 날짜, 시간, 장소
- 초대 문구
- 달력과 D-day
- 네이버·카카오 길찾기
- 지하철·버스·주차 안내
- 신랑·신부 계좌정보와 복사 버튼
- 사진 갤러리와 청첩장 주소 복사
- GitHub Pages 자동 빌드·배포

## 1. 먼저 새 GitHub 주소 입력하기

`wedding_config.py`를 열고 아래 두 주소의 `YOUR-GITHUB-ID`를 새 GitHub 아이디로 바꿉니다.

```python
'url': 'https://YOUR-GITHUB-ID.github.io/invitation/',
'share_url': 'https://YOUR-GITHUB-ID.github.io/invitation/',
```

저장소 이름을 `invitation`이 아닌 다른 이름으로 만들었다면 주소의 마지막 부분도 함께 바꿉니다.

## 2. 사진 넣기

이 다운로드본에는 기존 청첩장의 사진을 넣지 않았습니다.

### 대표사진

`photos/cover` 폴더에 사진 1장을 넣습니다.

- 권장 파일명: `cover.jpg`
- 세로형 또는 인물 중심 사진을 권장합니다.
- 여러 장이 있으면 파일명 순서상 첫 번째 사진만 사용됩니다.

### 갤러리

`photos/gallery` 폴더에 사진을 넣습니다.

- 권장 파일명: `01.jpg`, `02.jpg`, `03.jpg` …
- 파일명 순서대로 자동 배치됩니다.
- 사진이 없으면 갤러리 영역은 표시되지 않습니다.

### 약도

로얄파크컨벤션 약도가 `photos/map/map.png`에 포함되어 있습니다.

- 다른 약도로 바꾸려면 기존 `map.png`를 교체합니다.
- 권장 파일명: `map.jpg` 또는 `map.png`
- 약도를 제거해도 길찾기 버튼은 표시됩니다.

## 3. 미리보기와 빌드

Windows에서는 `실행_미리보기.bat`를 더블 클릭하면 브라우저에서 확인할 수 있습니다.

배포용 파일만 만들려면 `빌드만하기.bat`를 실행합니다. 완성된 파일은 `dist` 폴더에 저장됩니다.

## 4. 새 GitHub 저장소에 배포하기

1. 새 GitHub 계정에서 `invitation`이라는 공개 저장소를 만듭니다.
2. 이 폴더 안의 파일과 폴더를 새 저장소에 모두 업로드합니다.
3. 저장소의 `Settings` → `Pages`로 이동합니다.
4. `Build and deployment`의 `Source`를 `GitHub Actions`로 선택합니다.
5. `main` 브랜치에 파일이 올라오면 자동으로 빌드와 배포가 진행됩니다.

GitHub Pages 주소는 일반적으로 다음과 같습니다.

```text
https://GitHub아이디.github.io/저장소이름/
```
